# optimization-algorithms

Small, self-contained Java implementations of classic algorithms, run from a demo `App` class.

| Algorithm | File |
|---|---|
| Fibonacci (recursive) | `Fibonacci.java` |
| Knapsack (greedy selection in item order) | `Knapsack.java` |
| Dijkstra shortest path | `Dijkstra.java` |
| Bellman-Ford shortest path | `BellmanFord.java` |
| A* search | `AStar.java` |
| Travelling salesman (nearest-neighbour heuristic) | `TravellingSalesmanProblem.java` |

Build with `mvn compile`, then run the `App` class from `target/classes` (the demo asks for input on stdin).

**Status:** reference exercises, kept for reference.
